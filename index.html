Free Online Image Compressor

Shrink large photos in seconds while keeping visual quality — 100% free, no signup, and files never leave your browser.

How to Use the Image Compressor

  1. Choose one or more picture files from your device.
  2. Slide the quality bar between 10% and 100% to pick your compression level.
  3. Click "Compress Images" to process them locally on an HTML5 canvas.
  4. Download each reduced JPEG file using the generated link.

Features

  • Batch processing of multiple images in one click.
  • Live quality slider with instant percentage readout.
  • 100% client-side execution — your files never leave your browser.
  • Outputs optimized JPEG files with a compressed- filename prefix.

Frequently Asked Questions

Will my photos be stored on a server?

No. All compression runs locally inside your browser using HTML5 Canvas, so no image data is ever transmitted.

What file formats are supported?

JPEG, PNG, and WebP images are accepted; each output is encoded as a compressed JPEG.

Can I revert a compressed image?

Compression is lossy, so keep your original file if you ever need the uncompressed version.

Free Online Image Resizer

Adjust pixel dimensions of any picture instantly — keep aspect ratio or set exact width and height, 100% free with no signup.

How to Use the Image Resizer

  1. Pick a single image file from your computer or phone.
  2. Enter your target width, height, or both in pixels.
  3. Leave "Maintain aspect ratio" checked to prevent stretching, then click "Resize Image".
  4. Click the download link to save your resized PNG.

Features

  • Automatic proportional scaling when only one dimension is entered.
  • Lossless PNG output for crisp graphics and screenshots.
  • 100% free with no signup and zero server uploads.
  • Displays final pixel dimensions and file size in kilobytes.

Frequently Asked Questions

Will the resized image look stretched?

If "Maintain aspect ratio" is checked and you supply one dimension, the other is calculated proportionally.

Can I batch-resize several images?

This tool resizes one image at a time so you can control exact pixel dimensions.

What file type do I get?

The resized output is always exported as a lossless PNG file.

Free Online Image Converter

Switch between JPG, PNG, and WebP formats in a single click — 100% free, no signup, and files never leave your browser.

How to Use the Image Converter

  1. Select the image you want to convert.
  2. Choose JPG, PNG, or WebP from the target format dropdown.
  3. Click "Convert Image" to re-encode it locally.
  4. Download the converted file with its updated extension.

Features

  • Supports modern WebP alongside universal JPG and PNG formats.
  • All conversion happens in-browser, guaranteeing complete privacy.
  • Fast single-step workflow with no account or signup required.
  • Shows resulting format and file size before you download.

Frequently Asked Questions

Why choose WebP?

WebP typically produces smaller files than JPG or PNG at comparable visual quality, ideal for websites.

Can I convert animated GIFs?

This converter processes static images and exports the first frame.

Does the tool keep EXIF metadata?

No — canvas re-encoding strips EXIF metadata, keeping your output clean and lightweight.

Free Online Image to PDF

Turn one or many pictures into a printable A4 PDF document — 100% free, no signup, and files never leave your browser.

How to Use Image to PDF

  1. Choose all pictures you want to include in your PDF.
  2. Click "Create PDF" to place each image on its own A4 page.
  3. Wait a moment while jsPDF centers and scales each image.
  4. Download the combined images.pdf file.

Features

  • Automatic scaling to fit A4 (210×297 mm) while preserving aspect ratio.
  • Every image is centered cleanly on its own page.
  • Works completely offline in your browser — no server traffic.
  • 100% free with no watermarks or page limits.

Frequently Asked Questions

What page size is used?

Pages are standard A4 portrait (210 mm × 297 mm), with images scaled proportionally to fit.

Can I combine multiple photos into one PDF?

Yes — select multiple images in the file picker and each becomes a page in order.

Are my documents uploaded anywhere?

Never. jsPDF generates the PDF directly in browser memory.

Free Online PDF Merge

Combine two or more PDFs into a single document — 100% free, no signup, and files never leave your browser.

How to Use PDF Merge

  1. Select at least two PDF files from your device.
  2. Press "Merge PDFs" to copy all pages into one document.
  3. Download the combined merged.pdf file.

Features

  • Preserves original page quality, vector text, and layout.
  • Fast client-side merging powered by pdf-lib.
  • Zero-knowledge privacy — files never leave your computer.
  • 100% free with no watermarks or daily caps.

Frequently Asked Questions

Will bookmarks be kept?

pdf-lib copies page contents accurately, though interactive outlines/bookmarks are not merged.

How many PDFs can I merge?

Any number that fits comfortably in your browser's memory.

What about password-protected PDFs?

Encrypted PDFs must be unlocked before merging, as client-side merging cannot bypass encryption.

Is my input logged?

Never — QR generation happens entirely in your browser.

Free Online Password Generator

Create cryptographically strong, random passwords in one click — 100% free, no signup, and generated locally.

How to Use the Password Generator

  1. Drag the length slider between 6 and 64 characters (16+ recommended).
  2. Keep uppercase, lowercase, numbers, and symbols checked for maximum entropy.
  3. Click "Generate Password" to create a new random string.
  4. Click "Copy Password" to copy it directly to your clipboard.

Features

  • Uses Web Crypto API crypto.getRandomValues() for true randomness.
  • Customizable length from 6 to 64 characters.
  • One-click clipboard copy with confirmation.
  • 100% client-side — generated passwords never leave your browser.

Frequently Asked Questions

Why use crypto.getRandomValues instead of Math.random?

crypto.getRandomValues() uses your operating system's cryptographically secure random number generator, making passwords unpredictable.

Are generated passwords stored?

Never. They exist only on your screen until you copy or replace them.

What length is recommended?

At least 16 characters with all four character types enabled is recommended for important accounts.
